部署模式与使用路径 ​

OpenBot 以本地使用为默认路径，按需要增加手机联动、远程访问和常驻计算。部署方式决定程序在哪里运行、设备如何连接；官方账号决定用户身份、服务权益和经授权保存的数据。两者分别设计。 用户不应为了本地使用而被要求购买服务器或注册官方账号。

本页记录2026-10-20的产品方向与现有能力边界。四种模式是渐进选择，不是必须依次完成的安装步骤，也不表示以下全平台体验已经交付。

四种部署模式 ​

模式程序与数据位置使用方式谁负责运行维护
本地单机用户自己的电脑下载对应系统的客户端，打开本地工作空间；按引导选择模型或执行器用户；客户端尽量封装运行依赖
局域网联动本地电脑作为运行主机，手机作为控制端配对后通过同一可互通局域网连接，Bot 仍在主机上执行用户维护本地设备和网络
公网自托管有受保护公网入口的个人电脑或自有设备其他获授权设备通过 HTTPS 或受控私有通道接入用户维护入口、授权和主机在线状态
云端自托管阿里云等云服务器运行 Node/Hub，客户端按需接入常驻服务承接受支持的任务与连接；同步另由数据服务提供用户或其管理员维护服务器

官方未来也可提供托管服务，替用户承担服务器维护。这是一种服务交付方式，不要求用户先自行租用阿里云，也不把官方账号限制在云端部署中。见官方账号与数据服务与官方托管。

本地优先：下载后即可进入工作空间 ​

目标是 Mac、Windows、Linux 都提供经过各自平台验收的安装包，打开后即可创建本地工作空间，不要求先安装 Docker、数据库或自行部署后端。模型连接和可选执行器采用首次使用引导，复杂设置按需出现。

“下载即用”描述的是客户端启动与基础使用门槛，不表示内置无限免费模型。需要推理的功能仍须连接可用模型，或选择已适配、已安装并登录的本机执行器；模型费用和官方服务费用分别说明。首次打开不应自动启用远程控制或上传私有记忆。

当前已交付的桌面安装包为 Mac arm64。Windows、Linux图形客户端及其依赖打包、签名/分发、安装升级和真实交互仍需分别验收；Linux Node 已能运行，不等于 Linux 图形客户端已交付。准备要求见使用门槛，当前安装步骤见本机快速开始。

局域网：手机连接本地运行主机 ​

手机控制端与桌面主机完成配对后，复用主机上的 Bot 和受支持执行能力。手机是访问端，主机仍需开机、运行服务并保持网络可达；不能把“电脑休眠后手机仍可继续使用本机工具”作为默认承诺。

同一 Wi-Fi 名称不是连通的充分条件：访客网络隔离、防火墙、监听地址和 HTTPS 信任都可能影响连接。产品目标是提供发现/扫码、明确配对、可见连接状态和设备撤销，避免要求普通用户手填多个服务端口。现有手机预览和局域网分项联调不等于全平台、所有网络的一键联动已经验收。

公网：个人设备作为自托管主机 ​

个人 Mac 或其他设备可以提供服务器角色，但仅“拥有一个公网 IP”并不足以保证外部可用。还需要可达入口、受保护的连接、设备授权，以及持续在线的主机；动态地址和运营商 NAT 会影响可达性。优先复用受控私有网络或已有 SSH 隧道；需要直接公网访问时，再配置域名、HTTPS 入口和最小暴露面。

不要直接公开 Node 原始控制端口、浏览器调试端口或共享一枚永久主令牌给所有设备。公网自托管与云自托管沿用同一授权边界，不另外发明一套 Bot 协议。具体网络方式见连接与网络。

云端：常驻运行与多端数据分别建设 ​

云服务器提供常驻计算、连接入口和持久存储，可以不依赖个人电脑一直在线。阿里云是可选基础设施供应商，不是 OpenBot 的身份系统或必须绑定的模型服务商。已有服务器可按Linux Node 教程部署。

云端运行不自动等于多端同步。 同步需要明确的数据范围、用户/团队隔离、对象版本、冲突处理、删除传播、离线恢复和备份机制。连接远端 Node 不会自动复制本机模型密钥、浏览器登录、附件或记忆。云 Node 也不能在个人电脑关机时继续使用那台电脑的本机工具。

多端目标包括 Mac、Windows、Linux 客户端和手机访问端；只有完成对应客户端与同步协议验收，才能对外宣称支持。官方账号可以登记设备和获授权节点，也可以提供可选云端保存，但登录动作本身不授权上传所有本地数据。

不要把浏览器屏幕当作整台操作系统桌面。Linux Node、手机预览和 Mac 桌面的验收各自独立，不能互相替代。

本机与节点分别保存什么 ​

Mac 保留日常对话、模型连接和代理任务。Node 保留自己的模型凭据、Bot 定义、执行任务、浏览器资料和审计记录。

选择“自建节点”只改变该 Bot 的任务与屏幕执行位置。普通聊天与主脑仍在 Mac；模型 Key、附件、记忆和登录状态不会自动跨机器复制。节点与客户端需要配置相同的执行 Bot ID。

模型与服务器独立选择 ​

你可以把 Node 部署在阿里云、腾讯云、华为云或自己维护的设备上，同时使用另一家模型服务商的兼容 API。不同 Bot 也可以使用不同模型与 Harness。

云商购买与账户管理通过各自官网完成：

  • 阿里云
  • 腾讯云
  • 华为云

OpenBot 当前没有云资源代购、自动创建实例或统一计费接口。已有服务器可以按Linux Node 教程手动部署。

从两个浏览器开始 ​

当前部署配置默认限制为 2 CPU、4 GiB 内存，并允许最多两个任务并行。每个 Bot 使用独立的持久浏览器资料；同一 Bot 的任务串行执行。

这个配置是已验收原型的起点，不是任意网页或任意负载的容量承诺。先用两个只读网页任务验证模型、屏幕、接管和取消，再按实际负载调整资源。

常驻的含义 ​

服务可通过 systemd 随服务器启动，记录能够跨重启保留。未完成任务重启后标为中断，不静默重新执行。

客户端失联时，授权与输入会在边界暂停。常驻节点不等于无需审批地继续产生副作用；恢复连接后仍需查看新画面并显式交还。
