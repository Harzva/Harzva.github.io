运行与数据 ​

OpenBot 可以从自己的 Mac 开始。需要远端执行时，再连接自己的 Linux Node。本页集中说明运行条件；产品首页介绍使用场景，安装步骤见快速开始，各端交付范围见支持与验证。

模型、执行器和设备分别选择 ​

选择配置方式
模型连接兼容 API，逐 Bot 选择模型；账号、额度与服务费用由模型服务商管理
执行器默认 DSH，也可显式选择 Pi、兼容循环，或绑定已安装、已登录的受支持 CLI / ACP 执行器
运行设备Mac 本机，或显式连接自己的 Linux / Docker Node
界面细节默认保留对话与必要进度；工具记录按偏好展开，审批和停止仍可使用

本机执行器使用其所在机器的登录环境，接入成功不等于将订阅搬到云端。远程浏览器任务使用 Node 自己的 API、模型与 Harness 配置，不继承 Mac 的执行器绑定或订阅。配置方法分别见模型与连接、Harness和运行环境。

Bot 常驻与屏幕资源 ​

Bot 身份、记忆和任务记录持续保存，执行资源按任务需要申请。新建 Bot 不等于启动一个独立浏览器或容器；未获屏幕操作权限的 Bot 不能自行开启屏幕。

自建 Node 默认最多运行两个活跃浏览器，超出名额的屏幕申请等待，超时会明确失败。不在查看、无任务占用且未受人工接管保护的空闲屏幕可回收；有效人工接管期间保留。实际限制以节点配置为准；独立的浏览器资料与正在运行的屏幕是两个对象。

工作屏幕是 Chromium 浏览器环境，不代表完整 Mac、Windows 或 Linux 桌面。查看、审批、接管、交还与停止的行为见浏览器工作屏幕。

关闭应用或断开连接 ​

本机任务依赖本机应用和设备持续运行。退出应用会停止本机执行，仅关闭 Mac 窗口不等于退出；笔记本休眠也不能当作继续执行的保证。

远程任务依赖节点和控制租约。客户端断连或节点重启后，任务可能中断，不保证自动继续。未完成任务保留明确状态，避免静默重放已经产生副作用的操作；恢复前应核对实际结果，再明确交办下一步。

常开设备的部署方法见自建 Node，设备连接、HTTPS 和局域网条件见网络连接。当前没有官方托管购买入口。

登录与授权保存在什么地方 ​

浏览器资料可保留网站允许持久保存的登录状态。验证码、过期登录和网站限制仍需本人处理；OpenBot 不保证托管所有账号或永久保持登录。

GitHub 应用授权可由自己的 Node 加密保存凭据，再按主 Bot 与已开放的只读动作分配访问能力。它解决的是 Bot 使用 GitHub 的授权，不是用 GitHub 登录 OpenBot；本次已验收动作范围、撤销和续期边界见自托管应用授权。

本机资料、模型服务商和浏览器访问是不同的数据边界。选择远程节点后，节点使用自己的配置、凭据和持久状态，不会因为本机已登录就自动同步。备份和迁移应遵循配置参考，不要将凭据或浏览器资料提交到源码仓库。

官网体验与实际应用 ​

首页提供真实 App 浏览器界面的交互预览，使用合成 Bot 与示例对话。输入只存在于当前演示会话，不连接模型、真实账号、本机执行器或云节点；重置会清除本次预览修改。

闲置 20 秒且页面和预览均可见时可自动演示，手动操作立即暂停；可关闭自动演示并保留偏好。编辑过的示例保持手动，只有明确重置才允许恢复自动演示；重置仍保留已关闭的偏好。它用来体验界面，不是一次真实任务执行证明。

官网、预览界面、仓库源码和安装包分别发布。Mac 试点 DMG 的下载需要主仓权限，手机与云端的验证记录见支持范围。 平台与下载
