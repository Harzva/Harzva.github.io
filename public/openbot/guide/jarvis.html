贾维斯模式 ​

贾维斯模式让你日常面对一个主 Bot：它按职责向已有执行 Bot 派单，读回真实结果后汇总。执行 Bot 仍保留自己的身份、连接、模型、Harness、记忆与文件空间。

该模式是显示与协作入口。进入模式不会替任何 Bot 开启工具、安装执行器或补齐凭据。

1. 准备主脑和执行 Bot ​

  1. 为主 Bot 配置可用的 API 模型，在主 Bot 设置中显式开启工具。
  2. 创建或选择已有执行 Bot，写清职责，例如研究、核查与写作。
  3. 分别配置执行 Bot 的连接、模型和现有 Harness。可以共用连接，也可以各用不同服务。
  4. 文字任务无需给执行 Bot 开工具；需要它浏览网页时，再显式启用其工具。
  5. 绑定 CLI/ACP 的 Bot 还需本机已经安装并登录对应执行器。
接收者任务能力不包含
API 文字 Bot分析、写作、文字交付屏幕操作、再次派单
API 浏览器 Bot本 Bot 屏幕的六项浏览器工具文件工具、组织管理、递归派单
本机 CLI/ACP Bot已有执行器及工作目录API 浏览器任务模式

CLI 或未启用工具的主脑只能对话与规划，不能把计划表述为已经派单。连接与健康检查见模型与连接、Harness。

2. 开启并交办 ​

点击主 Bot 聊天头部“贾维斯模式”，或在“展开工作”中开启同名开关。侧栏聚焦主 Bot，执行 Bot 在后台保留，原有工作继续存在。

先验证一次文字协作：

让研究 Bot 列出这个方案需要核查的三项假设，让写作 Bot 整理一页提纲；等实际结果返回后，告诉我哪些是结论、哪些仍待核查。

需要网页核查时明确指定浏览器工作：

让研究 Bot 在自己的浏览器中核查 https://example.com 的标题和主要内容，不修改页面；读回实际结果后给我简报。

每次派单继续审批，页面修改也继续逐次审批。省略浏览器模式的 API 派单始终为文字任务，不会因接收者已开工具而自动升级。

3. 看懂运行反馈 ​

反馈对应事实
梳理主脑当前请求正在处理任务
分配或排队已有真实派单调用，或任务正在等待
执行至少一项实际工作仍在进行
待批或暂停对应 Bot 等待授权或控制权恢复
汇总当前父轮子任务已终结，且主脑已实际读回结果

最多显示三个执行 Bot 头像，其余收为数量。一个 Bot 等待授权而另一个仍工作时，两者保留各自状态；失败、取消和部分完成不会显示成全部成功。

“显示执行进度”可以隐藏简短反馈，系统“减少动态效果”保留静态状态。动画和终态图标不能代替任务结果、页面核查或持久记录。

4. 展开任务与关系图 ​

在“展开工作与执行 Bot”查看任务、待批项、结果和关系图。头像间的箭头来自实际委派记录；点击 Bot 或箭头查看关联任务。

执行 Bot 隐藏时，其审批仍显示真实身份，任务也能按真实任务 ID 停止。查看执行 Bot 完整会话会明确退出模式；普通退出会恢复仍存在的原会话。

切换显示模式不取消后台工作。结果沿既有路径保存到接收 Bot 的会话、文件与记忆，再由主脑读回；宿主保存结果文件不代表执行 Bot 获得文件工具。

5. 配置、权限与动作预算 ​

排队任务保存其执行配置指纹。排队期间若模型、连接、Harness 或工具权限变化，任务拒绝执行；运行中的模型请求与原生输入前也重新核对权限。

每轮使用开始时固定的配置，不静默改用其他连接或 Harness。没有模型、审批被拒、权限缺失或任务未完成时，应如实报告，不自动重派。

本机父轮的有限动作额度在派单前共享并全额预占。取消、入队失败或未用完不返还这份分配；预占也不代表动作已经执行。无法安全分配页面条件时会拒绝浏览器委派。

跨机器父任务目前不能携带次数规则或页面完成条件委派。遇到拒绝时先核对原任务与页面，不能删除约束后当作同一任务继续。

6. 停止与恢复 ​

停止主脑当前轮次只请求取消该轮子任务，独立任务继续。单项任务也可从任务列表停止，不依赖当前选中的 Bot。

取消不撤销已经发生的网页或执行器操作。结果待核查时先看页面与记录；等待超时应保留真实状态，不重复派单。

重启后未完成任务标为中断，不重跑执行器；结果回写失败只补保存。Node 断线后需重连、看新画面并显式交还，详见浏览器 Computer Use。

开发者本地验证 ​

在源码根目录运行以下受控 Electron 套件，分别检查文字协作和执行 Bot 浏览器链路。它们使用独立数据及本地模型替身，不调用真实模型：

shell
npm run test:jarvis
npm run test:worker-computer-use

源码与最终包的验证需分别记录，具体方式见参与开发。当前没有递归组织、无人值守调度或完整 L3/L4 长期验收。
