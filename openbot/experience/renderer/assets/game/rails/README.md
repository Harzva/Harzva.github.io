# rails 素材（原创）

本目录全部 SVG 为本项目原创绘制：以脚本组合基础几何图元（矩形/圆/路径）构成
侧视蒸汽机车字形、车皮牌卡面、车票版式与棋子，未临摹、未包装任何位图，
也没有引用任何在售桌游的美术。许可 MIT，与 `renderer/assets/game/LICENSES.md`
及 `manifest.json` 的逐文件 sha256 登记一致。

- train-*.svg：八色车皮牌面 + 机车牌（无文字，颜色由图形本身表达）。
- ticket.svg：运输任务票版式（城市与分值由界面层文本渲染，不进素材）。
- train-piece.svg：中立火车棋子剪影；地图上的已建线路标记由渲染层按玩家颜色内联绘制。
