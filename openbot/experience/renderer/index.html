API / MCP 与 AG-UI 说明

API 客户端向发布页显示的 API 地址发送请求，并将调用者令牌放在 Authorization: Bearer 请求头中。MCP 客户端使用对应的 MCP 地址；具体客户端配置以客户端说明为准。

API / MCP 用于提交或取消任务；AG-UI 仅观察已提交的任务。

不要把令牌放进 URL、本地存储或前端代码。小程序等远程客户端应通过自己的后端保存凭据并转发请求；本机地址不能作为公网地址使用。此入口不外发私人记忆或文件，也不开放 BOT 工具。

npm ci --prefix integrations
node integrations/channels/weixin.mjs login

node integrations/channels/weixin.mjs run

入口目标跟随自建节点的主 Bot，连接前请核对该节点的目标。扫码凭据保存在节点私有目录；当前支持文字私聊。
