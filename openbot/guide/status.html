支持范围与验证状态 ​

更新于 2026 年 11 月 17 日。公众可访问官网的交互预览和各端工程归档。私有主仓的 GitHub Releases 有 OpenBot v0.14.0 公司的试点 DMG。Bot Studio 1.0.33 已完成开发方本机安装验收，同版本安装包尚未上传。 平台与下载

网页用合成资料演示交互。桌面、云 Node、手机跨端和市场连接器分别记录验证范围。下表保留 0.10.9 至 0.14.0 的历史验收范围，1.0.33 的新能力与试点接入状态见技术架构报告。

如何阅读状态 ​

  • 已实现：当前源码存在该路径；使用仍需满足配置、权限和运行环境要求。
  • 原型或隔离验收：指定版本和独立资料中验证过，不等同于日常安装包或所有客户端已交付。
  • 待验收：还没有完整的实际闭环，不能用相邻路径的成功替代。
  • 规划：尚不提供可依赖的产品入口。

云端应用授权的验证范围 ​

实际 SDK stdio MCP 客户端已通过云端默认主 Bot，调用 app_connections_list 和 app_connection_call，由 github.profile.read 读回 GitHub 的真实身份资料。指定 Bot 获得连接与动作授权后才能使用，撤销后调用被拒绝；模型不取得应用 Token。

完成审计将应用调用归因到 Bot，并关联实际运行来源。本次成功后，云 Node 与微信接收器正常重启，连接、授权、审计与外部任务状态保持；MCP 重交同一逻辑请求返回既有任务结果，没有新增提供商调用。

GitHub 配额耗尽时的 403 会如实记录为失败，不自动换号重试。配额恢复后显式发起的新请求取得真实结果，原失败记录保留。任务的 done 状态与应用调用成功分别核验，不能以任务已终结替代工具结果。

本次结果不覆盖 Mac 安装包、桌面授权面板、自动 Token 续期、72 小时常驻、手机 App 公网 Hub 或新云双屏的验收。

验收与后续改进 ​

取消、重启、断连和人工接管分别验证。任务被中断时保留准确状态，不自动重放可能产生副作用的操作；“模型说完成”和健康检查都不能代替实际结果。

下一步重点是桌面应用授权入口、手机 LAN 与公网真实任务、自动 Token 续期和首次配置收尾。贡献前请确认修改影响的是哪条路径，并在 PR 中说明已验证与未验证项。

详细源码记录见仓库 docs/phone-link-status.md、docs/github-oauth-live-verification.json 和 docs/app-authorizations-verification.json。继续阅读快速开始、自建 Node或参与贡献。
