快速开始 ​

先在 Mac 上完成一次真实对话，再交办一项结果可以核对的小任务。想先看界面，可以打开产品首页的交互预览。预览使用示例 Bot 和任务，真实对话需要安装或启动桌面应用。

有 Apple 芯片 Mac 和可用的模型 API，或已登录的受支持本机智能体，就可以从本机开始。需要跨设备执行时，再按使用门槛选择手机连接或自建节点。

1. 选择启动方式 ​

方式适用场景前提
Mac 安装包日常使用、检查最终 AppMac arm64，已取得实际交付的 DMG
源码启动调试、贡献代码Node.js 22.19.0 或更新版本、npm
自建 Node让浏览器任务在自选服务器执行已可运行的桌面端、Linux 与 Docker

截至 2026 年 11 月 17 日，私有仓库的 GitHub Releases 最新带 Mac 安装包的是 OpenBot v0.14.0 公司试点预发布，附件包括 Apple 芯片版 DMG 和 SHA256SUMS。更名后的 Bot Studio 1.0.33 已在开发方本地 Mac 安装验收，同版本的安装包尚未上传到 Releases。取得仓库权限后，按所选发布页的附件和校验值下载。 试点版发布（需授权） · 平台与下载 · 验证状态

2. 启动应用 ​

先用发布页的 SHA-256 校验值核对 DMG，再打开 DMG，把其中的应用拖入“应用程序”。旧版试点安装包里的应用名称是 OpenBot.app。已有用户先退出应用并备份整个数据目录。签名、公证和安装说明以所下载版本的发布说明为准。

源码：先取得仓库，再在仓库根目录执行以下命令，使用独立开发数据目录：

shell
node --version
git clone https://github.com/Harzva/openbot.git
cd openbot
npm ci
OPENBOT_USERDATA="$HOME/Library/Application Support/openbot-dev" npm start

不要让源码运行与日常安装共用数据目录。目录中会保存 Bot 身份、对话、任务、凭据与浏览器登录状态；不要把它放进 Git 仓库。

复用本机智能体 ​

如果已有受支持的 CLI 智能体，先在原程序完成安装与登录，再打开侧栏底部的“智能体工作空间”，选中已发现的执行器并显式接入。对应 Bot 固定绑定该执行器与登录上下文，使用该执行器支持的订阅与模型。

扫描到程序不等于已验证登录、额度或全部能力。自动拆解与工具编排仍按API主Bot的现有条件执行，不能把CLI单Bot聊天当作已接通CLI主脑。

3. 保存一个模型连接 ​

  1. 打开设置中的 API 接入窗口，填写服务商提供的兼容 API Base URL、API Key 和准确模型名。
  2. 保存后向当前 Bot 发送一句简短消息，例如“只回复：连接已就绪”。
  3. 核对实际回复。“测试连接”检查接口可达性，收到所选模型的真实回复才验证了本次对话路径。
  4. 创建第二个 Bot 时，为它选择现有命名连接或新建连接，再分别设置模型和 Harness。

每个 Bot 可以使用不同连接、模型与现有 Harness。若多个 Bot 引用同一命名连接，编辑连接地址或 Key 会影响所有引用者；只想更改一个 Bot 时，先新建连接。完整规则见模型与连接。

4. 验证第一项任务 ​

回到主 Bot，在它的设置中显式开启工具。交办一项范围小、结果容易检查的工作，例如：

在你的文件空间写一份三行的工作清单，保存后告诉我文件名。

出现审批时核对目标和参数，再批准或拒绝。完成后到文件空间确认内容实际保存，并在“展开工作 → 任务”查看结果。模型说“完成”不是唯一凭据。

普通 Bot 的 API 工具限于自己的浏览器屏幕；文件和组织管理权限不因开启工具自动授予普通 Bot。本机 CLI/ACP 任务还需先安装并登录对应执行器，API 配置不会替它完成安装或登录。

5. 打开浏览器工作屏幕 ​

选择 Bot 的工作屏幕，先交办只读网页任务，核对页面预览与返回结论。每个 Bot 有独立浏览器资料与屏幕；这些是 Chromium 浏览器页面，不是完整 Mac 桌面。

操作用途
预览查看当前真实画面，不向 Agent 授予新的观察许可
人工接管停止旧 Agent 输入，自己处理页面或敏感登录
交还核对画面后恢复 Agent 控制；Agent 须重新观察
停止取消当前执行；已经发生的网页操作仍需核查

浏览器中的修改操作继续逐次审批。密码、验证码等敏感登录应由你接管处理，详见浏览器 Computer Use。

6. 让主脑协作 ​

先创建并配置执行 Bot，写明职责，然后在已启用工具的 API 主 Bot 聊天头部开启“贾维斯模式”。尝试让两个执行 Bot 分别完成文字分析，再由主脑读回结果。

若需要执行 Bot 浏览网页，还须为该 Bot 显式启用工具，并明确交办浏览器任务。模式切换本身不增加权限，详情见贾维斯模式。

7. 重启后核对记录 ​

退出并重新打开应用，确认 Bot 身份、连接、会话、文件和任务记录仍在。未完成任务应标为中断，不自动重跑。继续前先检查外部副作用，再明确交办下一步。

默认桌面数据目录是 ~/Library/Application Support/openbot。配置包不包含 API Key、节点令牌或浏览器登录状态，不能代替整目录备份。

下一步 ​

  • 从创建 Bot、审批、核对结果到接入外部渠道，见 Bot Studio 使用指南。
  • 调整模型或执行内核：模型与连接、Harness。
  • 远端执行：自建 Linux Node、网络与连接。
  • 查看使用的协议、集成与对外发布物，见技术架构与集成报告。参与修改见开发贡献指南。
