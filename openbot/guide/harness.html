执行内核与健康检测 ​

Harness 负责一次任务的模型与工具循环。OpenBot 通过薄 Adapter 接入驱动，自己持有 Bot 身份、记忆边界、权限、屏幕、任务与责任记录。切换内核不会增加权限，也不会重跑失败任务。

先完成模型配置，再为需要工具的 API Bot 选择执行路径。

当前内核 ​

选项驱动 ID实现与用途
跟随应用默认空值当前默认 DSH，可由明确的启动配置调整

DeepSeek模型API和DSH是两件事。默认使用DSH不要求绑定某个模型提供商；模型仍由每个Bot自己的连接决定。未知驱动报错，加载或执行失败不静默改用另一内核。

为一个 Bot 选择内核 ​

  1. 确认 Bot 的模型连接与模型名。
  2. 在该 Bot 的设置或高级设置中选择执行内核；留空跟随应用默认。
  3. 按任务需要明确开启工具，保存后开始新任务。
  4. 主动检测当前组合，再用范围小、结果可检查的任务验证实际能力。

API Bot分别拥有自己的runtime profile、工作目录和运行锁。已绑定的CLI/ACP沿用自己的执行器和登录上下文，不会因为选择API内核就自动改变其订阅或权限。

插件和能力的边界 ​

DSH插件按Bot profile装配，使用已审核的本地配置，不等于任意上游插件都能一键安装或获得宿主权限。OpenBot继续校验工具参数、审批、取消和副作用边界。

本版没有通用Harness在线升级市场。更新上游框架时固定版本、锁文件和Adapter契约，分别记录提供商与适配器版本，先验证拒绝、取消、停止、接管与不重放，再发布。

验证当前组合 ​

在Bot设置中主动点击模型与执行器检测。这会发送实际最小请求，可能使用服务额度。安装成功、版本号正常或发现登录文件都不能证明订阅可用。

状态含义
未检测当前组合没有有效检测记录
检测中请求尚未完成，可取消
已验证可用当时的模型和执行路径完成检测
不可用请求失败或未符合预期
需重新检测配置已变化或记录已过期

记录有效期30分钟。地址、Key、模型、Harness或Adapter版本变化后，旧结果不能沿用。检测回执不保存凭据、提示词或回复正文；通过检测也不授予工具权限或证明浏览器业务已完成。

DSH 四层概念、五态能力真值与受控桥接（源码演进候选） ​

为消除用户与插件作者对 DSH 内部概念、L2 工具加速器与固定执行器边界（D24/D25）的混淆，Bot Studio 在隔离工作树引入了一组统一投影与受控桥接模块（当前属源码候选，22 项集成测试通过，尚未合入正式安装包）：

四层概念 × 三种交付通道 ​

DSH 概念Bot Studio 产品映射交付通道规则安全边界
Bundle（能力包）可分发插件/能力包仅单步 kind: 'bundle' 支持 hub-auto-install（dsh.fish），另有 curated-manual 与 host-injected目录配置严格保持 {}，禁止携带私钥或凭据
Profile（装配档案）L4 Bot 装配身份与宿主设置不支持自动 Hub 安装（dshHubAutoInstallSupported: false）每 Bot 独立版本修订校验（profileRevision）与隔离空间
Agent Preset（角色预设）编排 HarnessPlan 的运行时预设仅作用于 activeInPlan 阶段不跨执行器偷偷放权或重写绑定
Workbench（工作台）从 HarnessPlan 投影出的确定性 tool-panel由主进程控制器直接编排（0 次 L1 LLM 网络调用）强制 workbenchRevision（64 位十六进制）、动作幂等键与同修订审批绑定

D24 五态能力真值（EffectiveCapabilityManifest） ​

渲染层与用户界面从 projectBotCapabilityManifest 获取只读五态事实，杜绝把“插件已安装”误判为“当前 Bot 可用”：

  1. installed：该能力包或工具是否真实安装在宿主清单中。
  2. bound：是否显式绑定到当前 Bot 的装配清单。
  3. activeInPlan：是否已进入当前运行时的 HarnessPlan。
  4. invoked：本轮或历史观察记录中是否真实被调用过。
  5. blocked：携带结构化阻塞码（如 Codex 固定执行器下显示 DSH_PLUGIN_FLOW_UNAVAILABLE、纯文本实例显示 DSH_INSTANCE_TEXT_ONLY、修订过期显示 DSH_WORKBENCH_STALE）；阻塞展示优先生效，但绝不擦除底层 installed 事实。

DeepSeek L2 加速器与 Codex × DSH 互补架构 ​

  • L2 加速器（src/deepseek-l2-tools.js）：封装 /v1/tools/{search,fetch,ocr,asr,tts} 与 deepseek_web_search / deepseek_read_url 内置工具，在宿主通过 getApiKey 实时注钥；公开清单与错误堆栈执行值级凭据扫描（assertNoSecretLiterals）、幂等脱敏（redactSecrets）、redirect: 'error' 与私有 IP SSRF 阻断，以及响应体积与超时上限。
  • Codex × DSH 受控桥接（D25 守卫）：Codex 类 Bot（agent:codex）绝不在进程内偷跑 runDshAgent 或调用 DSH 插件工作流；在每次桥接工具调用前重新执行 assertFixedExecutorSelection，仅开放宿主代理的 L2 感知工具（l2_search、l2_fetch、l2_ocr、l2_asr、l2_tts）和跨 Bot 异步委派工具 delegate_to_dsh_bot，由具备 DSH 能力的接收 Bot 执行后返回 openbot.task-receipt/1 回执。
