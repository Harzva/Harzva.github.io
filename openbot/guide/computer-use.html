浏览器 Computer Use ​

OpenBot提供每个 Bot 独立的 Chromium 浏览器工作屏幕，支持本机 Mac 与显式连接的自建 Linux Node。当前没有完整操作系统桌面、任意桌面应用或虚拟机控制接口。

开始一项浏览器任务 ​

  1. 为目标 Bot 保存模型连接、模型和 Harness；确认模型能处理这项任务需要的图像与工具调用。
  2. 在该 Bot 设置中显式开启工具。普通 API 对话不因模型支持工具而自动获得屏幕权限。
  3. 明确要访问的网页与目标，先选无副作用的阅读任务。
  4. 打开工作屏幕，核对 Bot、执行机器和页面。远端任务需先保存节点连接并连接执行会话。
  5. 出现修改操作审批时核对参数；完成后核查实际页面与任务结果。

可从这样的小任务开始：

在你的浏览器中打开 https://example.com，读取页面标题和第一段文字，不修改页面。

向执行 Bot 派发浏览器任务时必须明确选择浏览器模式；省略模式始终是文字任务，见贾维斯模式。

当前工具范围 ​

普通 API 执行 Bot 只拥有本 Bot 屏幕的六项工具：

工具用途关键边界
screen_open打开网页限 HTTP/HTTPS；不是任意协议启动器
screen_capture取得画面有效新观察才允许继续 Agent 输入
screen_click按截图坐标点击双击须明确要求，计为两次点击
screen_type输入普通文字不用于密码或验证码
screen_key发送允许的按键只接受工具声明的按键
screen_scroll上下滚动动作后取得新观察再决策

浏览器权限请求、弹窗、下载及非 HTTP 导航默认拒绝。浏览器工具不包含任意模型 JavaScript、Shell 或完整桌面控制；普通执行 Bot 也没有文件管理、组织管理和再次派单工具。

审批、观察与完成 ​

一次授权只批准对应调用。OpenBot 在输入真正发送前再次检查权限、控制权和动作预算；同一模型回复对同一屏幕最多执行一个有效输入，后续输入必须等待新观察。

动作发出后，OpenBot 不用动作前缓存补成成功截图。若新画面失败，任务保留“动作已发出、需要观察”的证据，后续输入会被阻止；先查看新画面，不直接重复点击。

人工预览不建立 Agent 的观察许可。两个新画面看起来相同也不代表业务失败，例如页面已经无法继续滚动；像素变化也不证明服务端业务已完成。

完成核查含义
confirmed宿主只读检查匹配本次声明的页面条件
unmet已检查，但页面条件尚未满足
unknown证据不足或存在未知副作用，需核查
not-required没有浏览器副作用，也未声明页面条件

模型自称完成不能把未知结果变成成功。页面条件只证明该次页面检查匹配，不能推定支付、服务端事务或任意异步流程已经完成。

人工接管与交还 ​

遇到登录、验证码、错误页面或需要自己操作时，点击“人工接管”。接管会使旧 Agent 观察和待执行输入失效；你可以在预览里操作目标屏幕。

核对页面后显式“交还”。交还后 Agent 必须重新观察，再决定下一步，旧输入不会自动回放。不同 Bot 屏幕独立，一个 Bot 被接管不等于所有 Bot 都停止。

停止与取消不能撤销已发生的外部操作。若动作可能已经发出，先检查页面和记录，再决定是否重新交办。

次数与结果不确定 ​

明确说明次数和完成条件，例如“点击按钮一次且不要重复，确认画面显示目标文字后结束”。支持范围内的次数会转换为持久动作预算；双击按两个点击单位计数。

已发出或结果未知的动作继续占用额度，不因超时、截图失败、取消或重启自动返还。额度不足或条件无法安全分配时会拒绝继续，不能用重复派单绕过。

当前有次数规则或页面完成条件的父任务不能跨机器委派。独立远端任务按其自己的已保存指令建立约束，完整的跨主机额度移交尚未实现。

Node 断线与恢复 ​

一个 Node 同时只允许一个控制客户端。租约到期或连接中断后，旧审批和旧屏幕输入失效，执行在模型或工具边界暂停。

恢复顺序是：重建 SSH 隧道 → 连接执行会话 → 核对新画面 → 显式交还。重新连接不自动恢复旧控制权，也不重放离线输入。

Node 重启将未完成任务标为 interrupted，不自动重派。提交回执丢失也不会换一个请求 ID 自动重试；先核查现有任务。

开发者本地验证 ​

从源码根目录运行受控套件，使用独立临时数据、本地页面与模型替身，不消耗真实模型额度：

shell
npm run test:computer-use
npm run test:observation

这些命令需要本机 Electron 运行环境；未指定 OPENBOT_E2E_APP 时验证源码，不能替代最终包。实现入口可查仓库 src/screen.js、src/tools.js、src/action-ledger.js 与 node/execution.js。
