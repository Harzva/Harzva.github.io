开始使用 Bot Studio ​

Bot Studio（原 OpenBot）是一个 Personal Bot Harness：你管理的是长期存在的 Bot，每个 Bot 可以有自己的职责、模型、执行内核、记忆和工作空间。任务与执行实例按需创建，身份与责任记录持续保留。

从自己的 Mac 开始，需要常开执行或多端访问时再增加 Node。云主机、模型服务和 Bot Studio 分别选择，不要求先购买官方托管服务。

网页交互预览无需安装。Mac 试点 DMG 需要仓库权限，1.0.33 为开发方本机验收版本。首次使用前请查看平台与下载和支持范围与验证状态。

选择一条最短路径 ​

你的目标起点需要准备
在 Mac 使用内置 Bot本机快速开始Mac arm64、模型 API 连接
复用已登录的本机智能体快速开始：本机智能体支持的 CLI 已安装并登录
手机访问自己的 Mac使用门槛与运行方式持续运行的 Mac、可互通局域网、独立预览 Hub 与设备授权
让任务在服务器持续执行部署 Linux NodeLinux、Docker、SSH、节点自己的模型配置
统一应用授权，供主 Bot 使用自托管应用授权自建 Node、专用 OAuth App、明确的 Bot 动作授权

手机联动仍是独立开发原型；USB 真实任务、LAN 配对和公网云端 App 是不同的验证范围。当前没有官方托管购买入口或跨设备自动发现。

从源码启动 ​

需要主仓访问权限、Node.js 22.19+ 与 npm。在仓库根目录执行：

bash
npm ci
OPENBOT_USERDATA="$HOME/Library/Application Support/openbot-dev" npm start

开发数据放在仓库外，与日常安装的数据分开。启动后先接入模型并确认真实文字回复，再按任务需要开启工具。

理解 OpenBot 的边界 ​

部分OpenBot 负责什么
Bot身份、职责、记忆边界、任务与结果记录
Harness适配默认 DSH、显式 Pi 或兼容工具循环；不随切换增加权限
工作屏幕独立 Chromium 浏览器、观察、逐次审批、人工接管与停止
Node在选定机器上执行，使用自己的配置、凭据和持久状态
应用授权服务器保存凭据，按 Bot 和动作授予能力；模型只接收业务结果

默认界面保留对话和必要进度，低频选项放在设置与高级入口。收起细节不会取消审批、停止和责任记录。
