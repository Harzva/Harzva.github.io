macOS ​

当前 GitHub Releases 最新的 DMG 是 OpenBot v0.14.0 公司试点预发布。

  • Apple Silicon（arm64）。取得仓库权限后，在试点发布页下载 OpenBot-0.14.0-arm64.dmg，并用同页 SHA256SUMS 核对校验值。
  • Intel（x86_64）。暂无安装包。

安装、模型接入与首次任务见本机快速开始。当前只有试点预览，尚无稳定渠道。没有仓库权限时可直接打开网页交互预览。

历史 v0.9.3 为开发预览，v0.10.9 为源码预览且没有对应二进制附件。Bot Studio 1.0.33 已在开发方安装验收，同版本安装包尚未上传。 GitHub Releases（需授权） · 支持范围

Windows ​

Windows 端（win32-x64）正在开发中，已完成三项核心工程适配并在 Windows 实机通过冒烟验证：

  • 原生窗口与标题栏（Feature #2）：采用 titleBarStyle: 'hidden' 与 46px 主题自适应 titleBarOverlay，支持深浅色模式同步。
  • 桌面窗口观察（Feature #1）：基于 desktopCapturer 实现 WinAppCapture 后端（app-observation-win32.cjs）。
  • 图标与打包管线（Feature #3）：通过 scripts/make-icon-win.cjs 生成 7 尺寸 PNG 嵌入的 build/icon.ico，由 scripts/package-win.mjs 生成 win32-x64 应用目录（工程归档见 openbot-win32-x64-packaging-kit-1.0.28.tar.gz）。

当前尚无公开 Windows 安装包（如签名 .exe / .msi 安装程序）。完成 Windows 端完整构建清单与公开发布签名验收后，再开放面向普通用户的正式安装包入口。

Android ​

移动端正在开发，优先作为电脑或云 Node 的控制端，用于扫码连接、交办任务和查看结果。已有独立 USB 和局域网预览验证，可获取 开发预览 APK 和 语音预览 APK。日常 Mac 整合、局域网真实任务及公网联动仍有待验项目，当前暂无稳定版或应用商店入口。

连接本机时，手机与电脑通常需要处于同一局域网，电脑需要在线；连接自己的云 Node 时，不要求同一 Wi-Fi。网络、HTTPS 和身份配对要求见连接与网络。

HarmonyOS ​

鸿蒙端（openbot-harmony/）采用 FA ArkUI 原生连接页与 ArkWeb 会话容器架构，支持华为平板与鸿蒙设备直连 Mac 或自建 Node：

  • 华为平板实机验证（v0.1.2）：已在华为平板 BKY-W10（HarmonyOS 4.2.0）完成真机签名安装、竖屏状态栏避让、局域网 HTTPS 扫码配对、冷启动地址保持与主 Bot 真实任务交办闭环（调试预览包见 openbot-tablet-0.1.2-huawei-debug.hap，通用 Public SDK 调试包见 openbot-public-sdk-debug.hap）。
  • 安装说明：华为真机直接安装调试 HAP 需匹配设备 UDID 调试Profile，或通过 hdc / DevEco Studio 签名安装；面向所有设备的华为应用市场公开版本尚在准备中。

iOS ​

iOS 端正在开发中，同时提供两种接入方式：

  • 独立原生客户端分包（openbot-ios v0.3.0）：基于 SwiftUI 与 WebKit 原生构建，已完成 9 组同源安全与连接单测、深浅色自适应主题、微信/飞书配对链接智能提纯、局域网延时与 TLS 根证书预检探针、常用宿主置顶以及内置离线演示工作台。通用架构（arm64 + x86_64）iOS 模拟器应用包归档见 openbot-ios-simulator-0.3.0-universal.zip。
  • 内置 /phone/ 手机网页通道：iPhone 与 iPad 用户也可直接通过电脑端「手机连接」二维码在 Safari 零安装扫码接入（网页端归档包见 openbot-mobile-web-1.0.28.tar.gz）。

当前可下载的是模拟器工程包和手机网页资源，真机签名、TestFlight 与 App Store 分发尚待验收。

服务器与桌面应用 ​

已有自建 Linux Node是远程执行服务，不等同于 Linux 桌面客户端。各端实际能力与前置条件见支持范围和运行方式。
